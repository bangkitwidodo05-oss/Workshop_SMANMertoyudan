Infografis Tahap 5 — Finalisasi & Ekspor

Uji Coba di Tab VIEW & Export ke HTML5 Mandiri

Checklist Sebelum Export

1. Simpan Proyek (.h5p): Tekan Ctrl + S agar file mentah proyek tersimpan aman dan bisa diedit kembali kapan saja.
2. Simulasi Penuh (Tab VIEW): Mainkan dari Stage 1 sampai Stage 5 (Finish) untuk memastikan semua tombol & koneksi berjalan mulus.
Siap Diekspor menjadi Web HTML5!

7 Langkah Export ke HTML5 Mandiri

1. Klik File → Export → HTML
2. Isi Margin X & Y = 20 (px)
3. Atur Max Width = 1024 (px)
4. Centang Restrict Width & Center
5. Atur Show Embed/Rights (opsional)
6. Klik Export → beri nama → Save
7. Hasil Akhir: File .html siap di-hosting gratis ke internet lewat GitHub Pages!

Hosting Gratis Tanpa Coding

Publikasi File HTML ke Web via GitHub Pages

Buka GitHub.com
LANGKAH 1

Ubah Nama File

Ubah nama file export LUMI menjadi index.html (huruf kecil semua).

gim.html → index.html
LANGKAH 2

Buat Repository

Login GitHub.com → klik + di kanan atas → New repository → isi nama repo (misal: gim-ipa).

Pilih Public → Create
LANGKAH 3

Upload File HTML

Klik uploading an existing file → seret index.html ke kotak unggah → klik Commit changes.

Commit Changes
LANGKAH 4

Aktifkan Pages

Buka tab Settings → klik menu Pages di kiri → pada Branch pilih main lalu klik Save.

Branch: main → Save
LANGKAH 5

Tautan Web Siap!

Refresh halaman setelah ±1 menit. Link web gim edukasi muncul di bagian atas siap dibagikan ke siswa!

username.github.io/gim
